# Data availability

The dataset is not included in this repository. It belongs to the Kaggle competition and cannot be redistributed.

Download it from the competition page (join the competition and accept the rules first):
https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data

Files used: `train.csv`, `test.csv`, `data_description.txt`, `sample_submission.csv`.
On Kaggle, attach the competition data to the notebook with "Add Input".
